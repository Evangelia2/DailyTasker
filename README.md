# DailyTasker – Android Task Management App

DailyTasker is a mobile task management application developed in Kotlin for Android.  
The app focuses on simplicity and usability, allowing users to efficiently organize and track their daily activities.


This project was designed to demonstrate core mobile development skills, including UI interaction, local data persistence, and structured application logic.
Users can create tasks, monitor their progress, and maintain an organized daily workflow through a clean and intuitive interface.

---

## Key Features

- Create and manage daily tasks  
- Mark tasks as completed  
- Real-time date and time display  
- Persistent task storage using JSON  
- Simple and user-friendly interface  

---

## 🛠 Tech Stack

- Kotlin  
- Android SDK  
- Android Studio  
- JSON
